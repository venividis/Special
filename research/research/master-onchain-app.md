## 0. Executive summary

ANIMA v7 ("MASTER") is the complete ANIMA 6.2 Genesis stack plus a **modular memory / cartridge system**. The relevant architecture for the GOAL is:

1. **The whole web app is stored on chain as immutable contract bytecode** (SSTORE2-style `AppChunk` data contracts, one STOP byte followed by at most 23,000 payload bytes), assembled by `OnchainApp` (≤64 chunks, verifies SHA-256 in the constructor), `OnchainAppDirectory` (≤16 leaves × 32 chunks = 512 chunks, archive schema 2), and `OnchainModuleDirectory` (archive schema 3: up to 32 independently versioned "functional feature archives" with exact dependency versions, commitment `sha256(abi.encode("anima.functional-runtime/1", …))`). The current application is **7,952,983 bytes** of HTML expanded, stored as **2,072,940 bytes** across **101 chunks** in **20 feature groups** (`onchain-app/confluence/manifest.json`), plus a **15,112,663-byte RAILGUN privacy worker** stored gzip-compressed as **4,596,329 bytes** across **7 shards / 200 chunks** (`onchain-app/privacy-worker/manifest.json`), plus a **707,014-byte Module Workbench** HTML document across **31 chunks** (`onchain-app/module-workbench/manifest.json`).
2. **The NFT "mints a website"**: `ConfluenceRenderer.render()` (`contracts/src/confluence/ConfluenceRenderer.sol:48-95`) returns `data:application/json;base64,…` whose `animation_url` is a small self-contained HTML **loader** (`ConfluenceLoader.html()`, generated from `web/confluence/chain-loader.mjs` + `module-loader.mjs`, stored itself in an `AppChunk` created in the renderer constructor). The loader carries `window.AWE_CHAIN_IDENTITY = {seed, genome, root, chainId, collection, tokenId, manifest, privacyResource, runtime, sha256, archiveVersion}` and, on click, uses `window.ethereum` or a user-supplied read-only HTTPS RPC to `eth_call` the chunk contracts at one pinned block, re-assembles, SHA-256-verifies every module, expanded payload and the directory commitment, and finally `document.write`s the recovered 7.9 MB application. No server, no IPFS, no URL.
3. **Wallet gating is done inside the recovered app, not by the loader**: `ConfluenceWallet.connect()` (`web/confluence/wallet.mjs:47-110`) calls `eth_requestAccounts`, checks `assertMintBinding(window.AWE_CHAIN_IDENTITY, collection, tokenId, chainId)` (the running page must be the page of the NFT it is operating), reads `ownerOf(tokenId)` / `accountOf(tokenId)` at one block, and throws `"This wallet does not own the selected NFT."` otherwise; every later action re-runs `assertOwner()` (chain, `eth_accounts[0]`, `ownerOf`, account `mode()==0`) and binds the review to the account's `sessionEpoch()`. The Module Workbench adds a second layer (`RegistryAdapter.context()` in `web/modules/adapter.mjs:11-17`) that additionally requires `currentOwner()` of the ERC-6551-style account to equal `ownerOf`. The shared-world server (`agent/worlds/server.mjs`) does SIWE-style sign-in bound to `anima:nft:<chain>:<collection>:<tokenId>:epoch:<sessionEpoch>` and re-resolves owner+epoch on every authenticated request.
4. **Modules ("cartridges")**: a holder installs immutable, publisher-namespaced releases into a per-NFT registry; each release is `keccak256(abi.encode(keccak256("anima.extension-release/1"), publisher, ReleaseInput, sha256(canonicalManifest)))`; state is append-only per `(collection, tokenId, moduleKey)` namespace with staged-then-activated schema migrations; installation history is a hash chain whose root is `rootOf[tokenId]`; every mutation requires the NFT's own account as `msg.sender` and `expectedRoot`/`expectedEpoch` (stale-review protection). A portable SDK (`@anima/modules` 1.0.0, 406,475-byte self-contained ESM bundle) packages, plans unsigned deployments, recovers and verifies. A **live Ethereum Sepolia deployment** of the collection + module system exists on branch `codex/deploy-on-testnet-and-mint-3-nfts-pj8cqs` (`docs/deployments/sepolia-11155111.json`, 37 transactions, tokens 1–3).

The reuse verdict in one line: the chunk-archive contracts, the manifest/commitment formats, the browser recovery loader, the module registry trio and the wallet-gating pattern are directly reusable (adapt); the Node "agent" services, Prism/worlds game server, RAILGUN worker and LayerZero OFT lane are off-chain services and should be dropped or treated as optional integrations for a strictly on-chain GOAL.

### 1.2 Build-side chunking (scripts, read for context)

- **`scripts/archive-confluence.mjs`** (71 lines): default path builds **archive version 3 "modular-gzip"** by calling `writeRuntimeModules()`; `--legacy` builds v1/v2 (one gzip bootstrap HTML, `<64` chunks → schema `awe.onchain-runtime/1`, otherwise `/2` with 32-chunk shards, hard limit `512 × 23000`).
- **`scripts/lib/runtime-modules.mjs`** (309 lines) is the heart of v3. `packageRuntimeModules(expanded)` groups every module of the verified import closure (`expanded.moduleGraph`, 117 entries) by its `web/<group>/` directory ("foundation" for `web/*.mjs`), builds one payload per group `{schema:'anima.functional-module/1', name, files:[{path, source, imports}]}` plus a `core-shell` payload `{schema, name:'core-shell', shell, moduleOrder}` where `shell` is the HTML with a `__ANIMA_VERIFIED_MODULE_IMPORT_MAP_7A9312__` marker in place of the import map. Each payload is canonical JSON → gzip level 9 `mtime:0` → wrapped as `{"schema":"anima.module-envelope/1","compression":"gzip","data":"<base64>"}` → split into 23,000-byte chunks (`archiveVersion` 2 with 32-chunk shards if >64 chunks). **Versions are per-group and increment only when the group's expanded SHA-256 changes** (`old.expandedSha256 === expandedHash ? old.version : old.version + 1`, line 56-60) — this is how "modules/cartridges are versioned" at the application level: unchanged feature archives are reused byte-for-byte across editions. The directory commitment is computed with the same `functionalCommitment()` the browser uses, and the build **round-trips** (`assembleFunctionalRuntime(...) !== expanded.html` → throw) before writing. `readRuntimeModules()` re-verifies every chunk hash, envelope canonicality (`compressed.toString('base64') !== envelope.data` rejected), `maxOutputLength` bounded gunzip, expanded hash, shard coverage, and exact HTML reconstruction.
- **`scripts/archive-privacy-resource.mjs`**: refuses to archive unless the worker matches `web/privacy/runtime-integrity.mjs` (`PRIVACY_RUNTIME = {sha256:40ef8c9a…, bytes:15112663, wallet:'10.9.0', broadcaster:'9.1.1', prover:'0.7.6'}`), gzip level 9, shards of `32 × 23000 = 736,000` bytes, ≤64 shards; writes `resource.gz` + `manifest.json` (`anima.onchain-resource/1`).
- **`scripts/modules-build-workbench.mjs`**: esbuild IIFE of `web/modules/standalone.mjs` inlined into `web/modules/index.html` with `workbench.css` inlined; rejects any external `src=`/`href=https:` (line 21); bound 1,048,576 bytes; chunked to 23,000; manifest `anima.module-workbench/1` with `inputs` map of every source hash (47 inputs including `packages/modules/*.mjs` and `web/vendor/ethers.min.js`).
- **`scripts/build-chain-loader.mjs`**: concatenates `chain-loader.mjs` + `module-loader.mjs` (imports/exports stripped, esbuild minifyWhitespace/minifySyntax, identifiers NOT mangled), wraps into the "Unfold your artifact" HTML and writes `ConfluenceLoader.sol`.
- **`scripts/verify-confluence.mjs`**: refuses the archive unless `buildManifestSha256` and `moduleGraph` match the current build, the directory contains exactly `manifest.json`, `runtime.html` and the listed chunks, the recovered HTML equals the fresh build byte-for-byte, the single `<script type=importmap>` contains exactly the graph keys as `data:text/javascript;base64,` URLs, and every embedded module passes `node --check`.

### 1.5 Recovery in the browser (the "mint a website" path)

1. `ConfluenceRenderer.render(collection, tokenId)` (`ConfluenceRenderer.sol:48-53`) → JSON `{name:"Anima Genesis #id", image: data:image/svg+xml (GenesisSVG), animation_url: data:text/html;base64, attributes:[Origin seed, Runtime SHA-256]}`. `_boot()` (lines 55-77) emits `<script>window.AWE_CHAIN_IDENTITY={seed,genome,root,chainId,collection,tokenId,manifest,privacyResource,runtime,sha256,archiveVersion};</script>` followed by the loader HTML read from the `loaderStore` AppChunk via `extcodecopy`. Comment: "Keeping the recovery program in immutable data avoids embedding its complete executable text in every renderer runtime (EIP-170). No URL or mutable loader."
2. The loader (`web/confluence/chain-loader.mjs:49-62`) shows a button "Unfold my artifact" and an optional "HTTPS RPC" field. Status text: "Reading only. No signature or transaction." It accepts only `https:` or `http://localhost|127.0.0.1|[::1]` RPCs, otherwise uses `window.ethereum.request`. `recoverArchive(request, config)` (lines 25-48): requires `eth_chainId == config.chainId` ("Select chain N in your wallet or RPC"), pins `eth_blockNumber`, calls `chunkCount()` (`0xf91f0937`), for v2 `schemaVersion()` (`0x4e2ce6d3`) and `byteLength()` (`0x02823108`), then `readChunk(i)` (`0x8f5281bf`) for each chunk, decodes the ABI bytes with `decodeArchiveChunk` (offset must be 32, length 1..23000), concatenates, checks length and `archiveSha256(bytes)` against `config.sha256`, and UTF-8 decodes fatally. The SHA-256 is a **dependency-free JS implementation** (`archiveSha256`) because "SHA-256 works in opaque data URLs, where SubtleCrypto may be unavailable" (line 2) — a load-bearing detail for data: URI pages.
3. For v3 (`module-loader.mjs:52-61`), `recoverFunctionalRuntime` reads `schemaVersion()==3`, `moduleCount()` (`0x334f7ac5`), `shellIndex()` (`0x7259f506`), `moduleAt(i)` (`0xd216d296`, 8 words), `dependencyCount(i)` (`0xb3a840da`), `dependencyAt(i,d)` (`0xb972ae05`), validates the directory against `config.sha256` with `validateFunctionalEntries` (bounds, dependency ordering/version equality, 64 MiB caps), then recovers each module archive **at the same pinned block** (`pinned` wrapper replaces `eth_blockNumber` and pins `eth_call` to `block`), expands with `DecompressionStream('gzip')` bounded by the committed `expandedBytes`, checks `expandedSha256`, checks `sha256(payload.name) == entry.id`, and `assembleFunctionalRuntime` verifies: shell has exactly one marker and no files; feature files have safe `web/…(.m)js` paths, unique, with `imports` that all resolve; **declared dependencies equal the actual cross-group imports** ("Declared dependencies differ from module imports"); shell pins every feature; `moduleOrder` is a complete permutation; then builds the import map `{"awe/<path>": "data:text/javascript;base64,…"}` with `<` escaped and caps the result at 64 MiB.
4. `document.open(); document.write(html); document.close()` replaces the loader with the application; `window.AWE_CHAIN_RPC` keeps the request function so the app can keep reading.
5. The application's wallet module then gates by ownership (§3.9).

The privacy worker is recovered the same way by `web/privacy/recover-resource.mjs:121-175` (selectors for `ShardedResource`, concurrency 4–8, per-shard sha, compressed sha, bounded gzip, expanded sha must equal the edition's pinned `PRIVACY_RUNTIME.sha256`, re-checks `eth_chainId` after decompression) and executed by `web/privacy/bridge.mjs:107-111` as a `new Worker(URL.createObjectURL(...))`. The loader comment: "sha256 and byteLength MUST come from the edition's trusted build/metadata, not a user-controlled resource."

## 2. `packages/modules` — the portable module SDK (publish / install / version / recover)

### 2.1 `packages/modules/core.mjs` (115 lines, 13,467 bytes) — portable format, no chain, no wallet

Public API (all exported):
- `RELEASE_SCHEMA='anima.extension-release/1'`, `HOST_API='anima.host/1'`, `ZERO_HASH`, `CAPABILITIES=['identity.read','journal.propose','state.read','state.write','transaction.propose']`, `LIMITS={manifestBytes:16384, storedBytes:11776000, expandedBytes:16777216, files:512, dependencies:16, graphReleases:64, graphDepth:16, chunkBytes:23000}` (line 8).
- `sha256(bytes) → '0x…'`, `asBytes(value)`, `canonicalJSON(value)` (sorted keys, safe integers only, rejects `-0`, no whitespace), `hashValue(v)` (lowercase bytes32), `safePath(v)` (≤240 chars, segments `^[A-Za-z0-9_][A-Za-z0-9_.-]*$`, no `.`/`..`).
- `validateManifest(m)` (lines 25-41): exact field set `schema,name,version,publisher,format,archive,entrypoint,hostAPI,dependencies,capabilities,stateSchema,predecessor[,resources,provenance]`; `name` `^[a-z0-9][a-z0-9_-]{0,63}$`; publisher lowercase nonzero address; version 1..2³²−1; `format ∈ {files, html}`; `archive={compression:'raw'|'gzip', storedHash, storedBytes(1..11,776,000), expandedHash, expandedBytes(1..16 MiB)}` (raw ⇒ stored == expanded); sorted unique dependencies (≤16) and capabilities; `state.*` capability requires nonzero `stateSchema`; optional `resources={maxRuntimeMs 1000..300000, maxStateBytes 0..32768}`, `provenance={sourceHash, buildHash}`; canonical bytes ≤ 16 KiB.
- `canonicalManifest(m)`, `manifestHash(m)` = sha256 of canonical UTF-8 (comment: "Domain is the schema field in the canonical bytes; hash includes that field."), `parseManifest(bytes, expectedHash)` (rejects non-canonical bytes), `verifyManifest`.
- `packageFiles(files, metadata, {compression='gzip'})` → `{manifest, manifestHash, contentId, archive, files}`; expanded payload is canonical JSON `{"schema":"anima.module-files/1","files":[{path,mime,data:<base64>,imports}]}` sorted by path. `packageLegacyHTML(html, metadata, {compression='raw'})` for a single HTML ≤ 1,048,576 bytes ("exceeds existing host bound").
- `verifyArchive(manifest, storedBytes)` → `{manifest, files, entrypoint}`: stored length/hash, bounded gunzip (`transform` cancels the stream when the budget is exceeded), expanded length/hash, envelope canonicality re-encoded and compared, base64 canonicality (`to64(b)!==s` rejected), entrypoint present.
- `resolveReleaseGraph(rootHashes, readRelease, {maxReleases=64, maxDepth=16, identityFor})` — DFS with cycle detection ("Cyclic release dependencies"), budget, identity recheck; returns dependency-first order.
- `planChunks(bytes, {existing})` → `{chunks:[{hash,bytes,payload,address,reused}], references, totalBytes, deployBytes}` — **content-addressed chunk deduplication** across a package and against already-deployed chunks.

## 13. Explicit answers

**How is any web UI delivered?** From chain, in three tiers: (a) `tokenURI` → base64 JSON → `animation_url` is a ~15 KB self-contained loader HTML (data: URI, no external references) that embeds the identity and the recovery program; (b) the loader recovers the 7.9 MB application from `OnchainModuleDirectory` → 20 `OnchainApp`/`OnchainAppDirectory` archives → 101 `AppChunk`s via `eth_call` at one pinned block, verifying 20 stored SHA-256s, 20 expanded SHA-256s, the dependency graph and the directory commitment before `document.write`; (c) the Module Workbench is a second 707 KB document anchored by `ModuleWorkbench` and recovered by the app ("also embedded in this edition's Atlas") or by the CLI. There is also a conventional static build (`dist/index.html`, 477 KB `index.html`) served by `npm start` for development; it is not the delivery mechanism of a minted token. IPFS is not used anywhere. The privacy worker is also on chain (`ShardedResource`), but RAILGUN circuits/POI/Waku remain external.

**How does it verify NFT ownership for access?** Not in the loader (reading the app is public — "Reading only. No signature or transaction."). Access to *functionality* is gated after the app is running: `ConfluenceWallet.connect` requires the injected wallet's account to equal `ownerOf(tokenId)` of the collection named in the page's own `AWE_CHAIN_IDENTITY` (so a page cannot be pointed at a different NFT), requires `accountOf(tokenId)` to have code, and every state-changing review captures `sessionEpoch()` and re-runs `assertOwner()` (chain, `eth_accounts[0]`, `ownerOf`, `mode()==0`) immediately before signing; the account contract itself enforces `currentOwner()`/epoch on chain (`TokenModuleRegistry._authorize`, `ChunkedCartridgeRegistry.launchManifest.authorized`). Off-chain services use SIWE-style challenges bound to `(chainId, collection, tokenId, sessionEpoch)` and re-check ownership on every request. Delegation ("authorised by its holder") exists only for the NFT account's session keys/`AgentPolicyGuard` grants (Bound mode); the owner-call adapter explicitly refuses proof-authorized ("sovereign") accounts.

## 14. Weaknesses / TODOs found

1. Deploying the app is expensive: 101 + 200 + 31 = 332 `AppChunk` transactions (each ~23 KB calldata; local plan 365 contract creations) plus archives. No CREATE2/content-addressed chunk reuse across deployers; the factory nonce race is only detected, not prevented.
2. Browser recovery is RPC-trust-based ("not a consensus/light-client proof"); the loader pins a block number, not a block hash (the SDK does pin the hash). A dishonest RPC can deny but not substitute (SHA-256 pinned in the token).
3. The loader data: URI runs with an opaque origin: no `localStorage`, no SubtleCrypto in some browsers (hence the JS SHA-256), and `document.write` of 7.9 MB; memory peak sampled 11,830,216 bytes JS heap (main page only).
4. `canonicalERC6551Compliance:false` — the account is a custom `SovereignAccount`; the module registry assumes `accountOf`, `artifactIdOfAccount`, `currentOwner`, `sessionEpoch`, `mode` (not ERC-6551 `token()`/`state()`).
5. Module state is public unless the client encrypts; "Decryption keys do not transfer automatically with an NFT." Encrypted journal uses AES-256-GCM + PBKDF2-SHA256 600,000 rounds.
6. Capability bridge is deliberately tiny (no fetch, no wallet, 4 KiB proposal calldata, 64 KiB state) — a swap/launchpad/vault *module* would need new capabilities.
7. Many services are off-chain Node processes (worlds, rehearsal, scenarios, agent host, keepers, proof service); `publicDeployment:null` for all of them. RAILGUN privacy only on 1/42161/137 and externally dependent; Groth16 setup is dev-only.
8. `PACKAGE-MANIFEST.json` says 6.2.0 while the project is 7.0.0; `system-manifest.json.modules` has 56 entries but the on-chain manifest has 20 archive groups (different notions of "module").
9. Workbench CSP/worker isolation is tested but "cannot guarantee process isolation or resistance to every resource-exhaustion strategy".
10. Not on `main`: the live Sepolia record and the Prism UI; `README` still says "No public contracts are deployed automatically".
