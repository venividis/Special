## 0. Executive summary

ANIMA v7 is an ERC-721 (`IDontFuckingBelieveIt`, symbol `IDFBI`) where each token gets a deterministic CREATE2 "NFT account" (`SovereignAccount`) at mint, a fully on-chain renderer whose `tokenURI` carries a self-verifying HTML bootstrap, and a constellation of ~85 peripheral contracts: a sealed "Genesis stack" (constant-product **swap** `NativeMarket`, **launchpad** `GenesisLaunchpad`, **vault** `TimeVault`, **social ledger** `WorldLedger`, journal `MemoryLedger`), a real Uniswap-v4 market (`V4GenesisMarket` + `PhoenixLaunchHook`), an NFT-estate exchange, a v7 **per-NFT installable module system** (`ExtensionReleaseRegistry` → `TokenModuleRegistry` → `ModuleStateStore` with on-chain state snapshots), cartridge NFTs that are byte-exact recoverable HTML, and a long tail of "extensions" (encrypted group chat, MLS transport, LayerZero OFT lane, state portal, agents/ERC-8183, auctions, fractional custody, governance, experimental DeFi, Groth16 quote proof).

The website is delivered **from chain**: `ConfluenceRenderer.render()` returns `data:application/json;base64` whose `animation_url` is a ~15 KB `data:text/html` loader (stored in an `AppChunk`) prefixed with `window.AWE_CHAIN_IDENTITY={...}`; that loader uses the viewer's wallet provider (or a user-entered HTTPS RPC) to `eth_call readChunk(i)` on an `OnchainApp`/`OnchainAppDirectory`/`OnchainModuleDirectory`, verifies SHA-256 in JS, and `document.write()`s the full app. **Ownership gating** is two-layered: the app's `ConfluenceWallet.connect()` reads `ownerOf(tokenId)` at a pinned block and refuses a wallet that is not the owner; and every state-changing contract requires `msg.sender == collection.accountOf(tokenId)` while the account itself only obeys `ownerOf(tokenId)` (`SovereignAccount._isController`), binding reviews to a `sessionEpoch` that increments on every transfer.

Toolchain: solc **0.8.30**, `viaIR: true`, optimizer runs **1,000**, `evmVersion` **cancun** by default / **shanghai** for `compile:local` (`IDFBI_EVM_TARGET`), compiled by `scripts/compile.mjs` with solc-js (no Foundry for production; one Forge fixture suite exists). The compile script **fails any contract over EIP-170's 24,576 bytes** and emits `reports/contract-sizes.json`. 204 compiler artifacts. Largest runtimes: `OperatingNFTGovernance` **24,192 B** (384 B of headroom), `SovereignAccountFactory` **23,423 B**, `SovereignAccount` **21,506 B**, `IDontFuckingBelieveIt` **20,940 B**.

Verdict in one line: **the account/custody-epoch model, the chunked on-chain app + viewer-side recovery loader, the module/state registries, TimeVault, WorldLedger and the launchpad/market pair are the parts to adapt; the sovereign/proof/agent/experimental/crosschain tail should be dropped or made optional.**

## 2. Architecture map (how the pieces compose)

```
mint (commit/reveal) ─▶ IDontFuckingBelieveIt ──createAccount──▶ SovereignAccountFactory ──CREATE2──▶ SovereignAccount(tokenId)
        │ tokenURI                                                                              │ execute / executeUtility / grantAction / executeInstrument
        ▼                                                                                       ▼  (msg.sender == ownerOf)
ConfluenceRenderer ──▶ JSON{image: GenesisSVG, animation_url: loader html + AWE_CHAIN_IDENTITY}   peripheral contracts check
        │ runtime = OnchainApp | OnchainAppDirectory | OnchainModuleDirectory (AppChunk*)         collection.accountOf(id)==msg.sender
        │ manifest = GenesisManifest.modulesOf(collection) -> [market, vault, memory, ledger, cartridges, exit]
        ▼
Genesis stack (sealed once by WorldLedger.sealModules):  NativeMarket (swap)  TimeVault (vault)  GenesisLaunchpad (launch)
                                                         MemoryLedger+JournalSwapRouter   VestedExitVault   EstateExchange (via configureEstateMarket)
                                                         ConsentGiftRouter  InstrumentRouter  CartridgeRegistry/CommissionedCartridges  EditionRegistry
                                                         CommissionEscrow  ExperimentGate/ExperimentCellFactory/BondedShelf  CommitmentIndex
v7 modules:  ModuleArchiveFactory ─▶ ExtensionReleaseRegistry ─▶ TokenModuleRegistry(+ModuleStateStore) ◀─ ModuleWorkbench.services()
             ChunkedCartridgeRegistry(+ArtifactBinding)
extensions (optional, separately deployed): privacy/*, crosschain/*, agents/*, access/*, markets/*, launch/*, governance/*, experimental/*, proof/*, strategies/*
```

Deployment order (from `scripts/lib/genesis-stack.mjs:25-54`): runtime archive → `GenesisManifest` → `ConfluenceRenderer(runtime, manifest, privacyResource)` → `ProofRouter(owner)` + `ThresholdAttestationVerifier` (`setSigner(owner)`, `router.setVerifier(1, verifier)`) → `IDontFuckingBelieveIt(owner, renderer, router, witness, royaltyReceiver=owner, royaltyBps=0)` → `SovereignAccountFactory(collection, router)` + `collection.setAccountFactory` → mint #1 → `WorldLedger(collection)` → `NativeMarket(ledger)`, `TimeVault(ledger)`, `GenesisLaunchpad(ledger)` → `MemoryLedger(collection)` + `JournalSwapRouter(memory, market)` + `memory.installRouter(journal)` → `VestedExitVault(collection, market)`, `ExperimentCellFactory`, `EditionRegistry`, `CommissionEscrow`, `ExperimentGate(owner)`, `BondedShelf`, `ConsentGiftRouter(ledger,market,vault)`, `InstrumentRouter(...)`, `ArtifactBinding`, `CartridgeRegistry(binding)`, `CommissionedCartridges`, `CommitmentIndex(cells, tracked)`, `EstateExchange(ledger, commitments)` → `ledger.configureEstateMarket(estate)` → `ledger.sealModules(market, vault, launch)` → `manifest.publish(collection, [market, vault, memory, ledger, cartridges, exit])`.

Two cross-cutting primitives appear everywhere and are the real "protocol":

1. **Identity = NFT account.** Peripheral contracts never ask the wallet; they ask `collection.accountOf(identity) == msg.sender` (`ProtocolGuard._identity`, `ProtocolPrimitives.sol:62-65`: "Zero means an unbound wallet/contract address, never a claimed NFT identity.").
2. **Custody epoch.** `SovereignAccount.sessionEpoch` is bumped by the collection on every transfer and on ascension. Every long-lived grant, invitation, plan, listing or review stores the epoch and re-reads it (`VestedExitVault._sameCustody`, `WorldLedger.memberActive`, `TokenModuleRegistry._authorize`, `EstateExchange.snapshot`, `AgentPolicyGuard.run`, `LaunchRegistry._context`, …).

#### `SovereignAccount` — `core/SovereignAccount.sol` (571 lines, **21,506 B**)
Purpose: "Deterministic account whose controller follows an NFT until irreversible sovereign promotion." One instance per token, CREATE2 from the factory, constructor reads `initialStateOf(tokenId)` from the collection and seeds `stateRoot/memoryRoot/auditRoot`.

API (Bound mode, `onlyController` = `msg.sender == ownerOf(tokenId)`, `onlyBound`):
- `execute(address target,uint256 value,bytes data) payable nonReentrant returns(bytes)` — generic call, nonce++, audit append.
- `executeUtility(uint256 expectedNonce,uint48 deadline,address asset,address target,uint256 value,bytes data,uint256 allowanceAmount) payable` — "One approved action: exact allowance -> call -> allowance reset, atomically." Post-call check: "A callback cannot transfer the NFT mid-recipe then continue spending its new owner's funds." (`currentOwner()!=holder || sessionEpoch!=epoch || mode!=Bound ⇒ revert`). `utilityVersion()` = keccak("idfbi/four-chambers/1.3").
- Instrument grants (section "1.6 bounded instrument grants"): `adoptInstrument(address registry,bytes32 edition) returns(bytes32 key)` (registry must answer `editionCommitment(bytes32)`; **7-day** `readyAt` delay; pins `registry.codehash`); `grantInstrument(bytes32 adoption,address caller,address target,address asset,bytes32 dataHash,uint112 perCall,uint112 budget,uint96 value,uint48 expires,uint32 maxCalls) returns(uint256)`; `grantAction(address caller,address target,address asset,bytes32 dataHash,uint112 perCall,uint112 budget,uint96 value,uint48 expires,uint32 maxCalls) returns(uint256)` (bounds: target has code, `expires <= now+30 days`, `maxCalls 1..100`, asset 0 ⇒ `value<=perCall`, else `value==0`); `actionGrant(uint256) view returns(InstrumentGrant)`; `revokeInstrument(uint256)`; `executeInstrument(uint256 id,uint256 expectedNonce,bytes data) onlyBound nonReentrant returns(bytes)` — callable by the grant's `caller`, requires `keccak256(data)==dataHash`, `target.codehash==targetCodeHash`, epoch match; measures **net debit by balance difference** (`spent = before-after`), enforces `spent<=perCall && spent<=remaining`, approves exactly `min(remaining,perCall)` then resets to 0.
- `revokeSession(address)`; legacy `createSession(...)`/`executeSession(...)` **always revert `InvalidSession`** ("Legacy selector sessions cannot express token budgets. New editions reject them.").
- `evolveBound(uint256 expectedNonce,bytes32 newGenome,bytes32 newMemoryRoot,bytes32 evidenceHash)` — sets roots then calls `collection.commitEvolution` ("All state changes revert if the collection rejects the proposed transition.").
- `invalidateSessionsOnTransfer()` — collection only, `++sessionEpoch` ("Old session keys must not follow the NFT to its new owner. No nonReentrant modifier: a proof-authorized transfer calls back here from inside executeVerified.").
- Sovereign path: `configureSovereignVerifier(uint32 id)` (owner, Bound); `promoteSovereign(bytes32,uint96,uint32)` (collection only, once; requires `sovereignAuthorityReady()`); `intentStatement(Intent) view`; `executeVerified(Intent intent,bytes data,bytes proof) payable nonReentrant` ("Anyone may relay a valid proof; authority comes from the proof, not the relayer."); `sovereignAuthorityReady() view` — true only if `proofRouter.codehash == keccak256(type(ProofRouter).runtimeCode)` and `frozenAuthority(id)`.
- Interfaces: `token() returns(chainId, collection, tokenId)`, `state() returns(actionNonce)`, `isValidSigner(address,bytes) returns(bytes4 0x523e3260)` (Bound + controller only — "A target/selector grant is not general external signing authority."), `isValidSignature(bytes32,bytes)` (Bound: owner's ECDSA/1271 via `SignatureChecker`; Sovereign: `proofApprovedDigest[hash]`), `onERC721Received` (**rejects tokens from its own collection**: "Same-root-collection safe nesting remains disabled until ownership-cycle rules are separately implemented."), `onERC1155Received`, `onERC1155BatchReceived`, `supportsInterface` (165, 1271 `0x1626ba7e`, `0x6faff5f1`, `0x4e2312e0`), `receive()`.

Storage: immutables `collection, tokenId, proofRouter`; `mode`, `constitutionHash`, `stateRoot`, `memoryRoot`, `auditRoot`, `actionNonce`, `sessionEpoch=1`, `lastActionAt`, `maxValuePerAction`, `minActionDelay`, `sovereignVerifierId/Verifier/CodeHash/Epoch`, `sessions`, `proofApprovedDigest`, `_entered`; later: `adoptedInstruments`, `instrumentGrants`, `instrumentGrantCount`, `instrumentRevision`.
Events: `Executed(nonce,operator,target,value,statement,resultHash,newAuditRoot)`, `SessionConfigured/Revoked`, `SessionEpochInvalidated`, `Ascended`, `VerifiedIntentExecuted`, `UtilityExecuted`, `InstrumentAdopted/Granted/Used/PermissionRevoked`, `SovereignVerifierConfigured`. Errors: `Unauthorized, InvalidTarget, InvalidSession, SessionExpired, SessionExhausted, AlreadySovereign, SovereignOnly, BoundOnly, InvalidIntent, InvalidProof, ValueLimitExceeded, CooldownActive, Reentrancy`.

Audit root: every action appends `keccak256(abi.encode(auditRoot,nonce,operator,target,value,statement,keccak256(result),block.number,block.timestamp))` (`_appendAudit`, l.541-562) — the on-chain "worldline" that the renderer and `EstateExchange.snapshot` consume.

ERC status: ERC-1271 yes; ERC-6551 **interface-shaped but not canonical** (no ERC-6551 registry/proxy; `system-manifest.json` says `"canonicalERC6551Compliance": false`). ERC-721/1155 receiver yes. No ERC-4337.

Tests: `contracts.integration.test.mjs`, `security/owner-safety.test.mjs` ("exact token budgets reject changed recipient, excess spend, replay, revoke and old custody"), `extensions/agents.contracts.test.mjs` (F03 operator through real grants), `extensions/desk.test.mjs` ("Workbench funds computed House principal through real SovereignAccount.executeUtility and resets its exact approval atomically"), `mocks/ReentrantProbe.sol` (reentrancy through `execute`).

**Verdict: adapt.** The Bound-mode API (`execute`, `executeUtility`, `grantAction`/`executeInstrument`, epoch invalidation, 1271, receivers) is exactly the "wallet inside the NFT" the GOAL needs. Remove the Sovereign/proof branch (≈40% of the bytecode) and consider implementing as an ERC-6551 account behind the canonical registry so marketplaces/wallets recognise it. Keep the net-debit-by-balance budget design and the 7-day adoption delay idea.

## 4. How the web UI is delivered, and how it verifies NFT ownership (explicit answers)

**Delivery — from chain, via the token's own metadata, with viewer-side recovery.**
1. `IDontFuckingBelieveIt.tokenURI(id)` → `ConfluenceRenderer.render(collection,id)` → `data:application/json;base64,…` with `image` = base64 SVG (`GenesisSVG`) and `animation_url` = `data:text/html;base64,…` (`ConfluenceRenderer.sol:87-89`).
2. The HTML is `<script>window.AWE_CHAIN_IDENTITY={seed,genome,root,chainId,collection,tokenId,manifest,privacyResource,runtime,sha256,archiveVersion}</script>` + the ~15 KB `ConfluenceLoader` page read from an `AppChunk` (`_boot`, l.55-77). It contains no app code — only a verifier/loader.
3. When opened (wallet in-app browser, or any browser with a pasted HTTPS/localhost RPC), the loader pins a block, `eth_call`s `chunkCount/readChunk(i)` on the `runtime` archive (`OnchainApp` v1 ≤64 chunks, `OnchainAppDirectory` v2 ≤512, `OnchainModuleDirectory` v3 ≤32 gzip "functional modules"), re-hashes everything with its own SHA-256, assembles an import map of `data:` ES modules for v3, and `document.write()`s the app. Measured: the Genesis app (7,952,983 bytes) plus the workbench (707,014 bytes) recovered exactly in **6,080 ms** against a local provider in the Chromium gate; the local `onchain-app/manifest.json` HTML archive is 409,658 bytes in 18 chunks.
4. Service discovery for the app: `AWE_CHAIN_IDENTITY.manifest` → `GenesisManifest.modulesOf(collection)` → `[market, vault, journal(MemoryLedger), ledger(WorldLedger), cartridges, exit]` (`wallet.mjs:116-133`); the v7 workbench is a separate `ModuleWorkbench` whose `services()` returns registry/state-store addresses.
5. There is **no server, no IPFS**; there is also **no `web3://`/ERC-5219 router or ERC-4804 URL** — the "website" is reachable only as a `data:` URL (from `tokenURI`) or by recovering it with the SDK/CLI (`npm run modules:recover-workbench`) and serving locally. A hosted dev copy (`index.html`, 477 KB) exists for development only. The loader needs `window.ethereum` or a user-typed RPC, so marketplace iframes that block RPC will show the loader page, not the app.
6. Companion recoverable artefacts use the same chunk pattern: cartridges (`ChunkedCartridgeRegistry.contentOf`), module releases/state (`ModuleArchiveFactory`/`ModuleStateStore`), the privacy worker (`ShardedResource`).

**Ownership verification — client check plus contract enforcement; no signatures/SIWE because there is no server.**
- Client (`web/confluence/wallet.mjs:49-93`): `ConfluenceWallet.connect(collection, tokenId)` → `assertMintBinding` (the page's baked identity must match the selected collection/token/chain) → `eth_requestAccounts` → reads `ownerOf`, `accountOf`, `renderSnapshot` **at one pinned block** → `if (owner.toLowerCase() !== address.toLowerCase()) throw Error("This wallet does not own the selected NFT.")` → requires code at the account. `accountsChanged`/`chainChanged` invalidate the session (`revision++`). The workbench (`web/modules/adapter.mjs:12-17`, `embedded.mjs:18046-18048`) additionally requires `collection.ownerOf(id) == account.currentOwner()` and the connected address, and binds every prepared review to `{owner, epoch}` (`sameAuthority`, "NFT ownership or custody epoch changed.").
- Chain: nothing trusts the UI. Every action is a transaction from the owner EOA to `SovereignAccount.execute/executeUtility` (or `executeInstrument` by a grantee), and `onlyController` is `msg.sender == IERC721Control(collection).ownerOf(tokenId)` (`SovereignAccount.sol:504-506`). Peripheral contracts gate on `collection.accountOf(identity) == msg.sender` (`ProtocolGuard._identity`), and the module registry also checks `currentOwner()==ownerOf` and the `sessionEpoch` (`TokenModuleRegistry._authorize`). A buyer's first transfer bumps `sessionEpoch`, which retires every grant, invitation, plan and pending review of the previous owner.
- Not used for gating: ERC-4907 `userOf` (renters cannot act through the account), ERC-1271 (only used when third parties verify the account's signature), approvals/operators (explicitly denied spending/identity authority).

## 7. Known weaknesses, TODOs and traps

1. **Not canonical ERC-6551.** Accounts are CREATE2'd by a bespoke factory, no ERC-6551 registry/proxy, so wallets/marketplaces will not auto-discover the account. (`system-manifest.json: canonicalERC6551Compliance:false`.)
2. **Size cliff.** `SovereignAccountFactory` (23,423 B, embeds the account creation code) and `OperatingNFTGovernance` (24,192 B) leave <1.2 KB / 384 B. Any feature added to the account must shrink something else or move to a module.
3. **Admin keys exist until frozen:** collection owner (`setRoyalty`, `setAccountFactory` once), `ProofRouter`/`ThresholdAttestationVerifier`/`OmnichainWitnessRegistry` owners, `WorldLedger` configurator (until `sealModules`), `MemoryLedger.installRouter`, `V4GenesisMarket.installHook`, `ExperimentGate` guardian, `OwnerFeeRouter` owner. "Immutable" is a deployment-time discipline (deploy → seal/freeze), not a property of the code.
4. **Swap v1 (`NativeMarket`) has no LP layer**: liquidity is permanently locked, only ETH-paired launchpad tokens, 2-hop max, no oracle; fees accrue to reserves (holders of nothing). The v4 market fixes this but needs a mined hook address and a PoolManager on the target chain.
5. **Launchpad** is pro-rata batch only; contributions keyed by `msg.sender`; no allowlists/tiers/KYC hooks; vesting starts at settle time; `about` ≤1 KiB; "NOT… a claim of Sybil/MEV resistance".
6. **WorldLedger stores message bodies in storage** (1 KiB cap) — reads are trivial but writes cost ~20k gas per 32 B plus events. `_epoch()` staticcalls arbitrary actor code. No deletion, only `hidden` flag.
7. **Loader needs an RPC in the viewer**: `animation_url` is a bootstrap, not the app; OpenSea-style sandboxed iframes without `window.ethereum` will show the "Unfold" page only. No `web3://`/ERC-5219/ERC-4804 route exists in this repo (IPSEITY has one).
8. **Mixed error style**: custom errors in most files but `require("STRING")` in `GenesisToken`, `OnchainApp*`, `ShardedResource`, `ZkVmVerifierAdapters`, `V4Strategies`, `LayerZeroInterfaces`, crosschain, `GenesisManifest`, `ExperimentCellFactory`, `NFTAuctionFactory`.
9. **Minified one-line Solidity** in many files (`NativeMarket`, `GenesisLaunchpad`, `TimeVault`, `SovereignAccount` instrument section, all of `operating/`, `extensions/experimental`) — hard to audit/diff; no NatSpec on most functions.
10. **Dead vendored code**: solady `ERC1155`, `SafeTransferLib`, `SignatureCheckerLib`, `ReentrancyGuard` are compiled but unused.
11. **ABI coupling by returndata length**: `EstateExchange.lockHash`/`_inventory` require `lockInfo` to return exactly 320 bytes; `MLSGroupChat.announceMigration` decodes `rooms(uint256)` by first word.
12. **State snapshots are expensive on L1** (7.7-7.9 M gas for 32 KiB) — designed for the EIP-7825 cap, fine on L2.
13. **ERC-4907 user is decorative**: `userOf` never grants account authority; `EstateExchange` refuses to list a token with an active user.
14. **Experimental tail is testnet-only by construction** (`ExperimentGate` chain allowlist) and explicitly unaudited ("No… independent security audit is claimed").
15. **Test infra**: ganache 7.9.2 (archived upstream), one Forge fixture; the organism lifecycle is a single 750-line test.
16. `revealAwakening` uses `blockhash(commit+1)` so a reveal more than 256 blocks late is impossible anyway (MAX 200 enforced); `cancelExpiredAwakening` only after 200 blocks.
17. `OwnerFeeRouter._allocate` loops ≤64 recipients on every deposit (gas scales with recipients).
18. Names/branding ("i dont fucking believe it!", "IDFBI", "ANIMA", "AWE") are baked into constants, domains and selectors in the loader; every hash domain string must be re-chosen.
19. Dependency pins on **draft** specs: ERC-8004 (binding), ERC-8183 ("retrieved 2026-09-12"), ERC-8048 interface id `0xdf670be1`, LayerZero oft-evm 4.0.1, v4-core commit `d153b04` — re-verify before reuse.
20. The factory's CREATE-based module archives mean predicted addresses are invalidated by concurrent use (documented; plans fail closed).

## 9. Unique ideas worth carrying forward

1. **Viewer-side recovery**: `tokenURI` ships a ~15 KB self-verifying loader that fetches, hashes and boots a multi-MB app from chunk contracts using the viewer's own RPC — no size pressure on `tokenURI`, full app still "in the NFT".
2. **STOP-prefixed data contracts + constructor-verified archives + versioned directories** (v1 flat, v2 nested, v3 functional modules with gzip envelopes and an import map); root commitments exclude addresses so bytes can be reused across editions.
3. **Custody epoch everywhere**: one counter on the account, bumped by the collection on transfer, consulted by every peripheral; invitations/moderation require the epoch of *both* grantor and recipient; reviews in the UI are bound to `{owner, epoch}`.
4. **Approvals never confer authority** (`_isMutableAuthority`), accounts cannot hold their own collection, tokens cannot be sent into any sibling account (`ForbiddenTransferTarget`).
5. **Net-debit-measured grants** (`executeInstrument` measures `balanceBefore-balanceAfter` against `perCall`/`remaining`, pins target codehash, resets allowance, re-checks custody after the call) and `executeUtility`'s exact-allowance-then-reset recipe.
6. **Per-NFT module registry with atomic release+state activation, append-only roots/history, staging before activation, and an independent namespace index** so lost receipts are recoverable.
7. **Reflection branches in the journal**: former owners keep their own thread without touching the canonical head; journaled swaps bind the fill to the note.
8. **Sealed Genesis stack + protocol-attributed activity feed**: `WorldLedger.record` accepts only the sealed market/vault/launchpad/estate, giving a trustworthy on-chain "timeline" and `postWithReceipt` to chat about a specific trade.
9. **Estate sale with declared-inventory covenant** re-verified before and after transfer, hashing the account's audit root, instrument revision and module commitments.
10. **Swap-and-lock** in one call (`lockUntil` argument) and a drop-in ABI shared by the constant-product and the v4 market so routers/vaults don't care which is deployed.
11. **Hook economics**: dynamic fee ramp, seed principal lock that still allows fee pokes, unlock-callback commitment hash.
12. **64-slot streaming uniform-price auction** that fits in a fixed array and clears per checkpoint.
13. **Group chat epoch freeze** when any member's key generation changes; sorted complete roster prevents omissions.
14. **Deployment discipline**: EIP-170 gate in the compiler script, EIP-7825 gas-cap awareness in tests, unsigned reviewable plans with CREATE nonce prediction, publish-once manifests.
