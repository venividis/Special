# Research workspace

Provenance for the unified protocol: everything the design was derived from.

- `research/<repo-area>.md|.json` — source-level reads of each donor repository
  (ANIMA = Cutting-edge-technologically-advanced-NFT, IPSEITY = Most-Advanced-NFT-Possible,
  MASTER = MASTER-NFT-PROJECT / ANIMA v7, Garden = Pixel-Garden), with reuse verdicts.
- `research/<repo>-branches-N.md|.json` — scans of every unmerged branch (security fixes,
  research, UI work, deployment records).
- `research/r-<topic>.md|.json` — 2026 ecosystem research: accounts, social, launchpads, swaps,
  vaults, on-chain delivery, wallet gating, agents, NFT standards, security, prior art,
  privacy and chain economics.
- `dossiers/` — one synthesis per donor repository plus the consolidated research brief.
- `designs/` — the design brief, three candidate architectures (minimal-delta, clean-room,
  product-first) and two judge verdicts.
- `toolchain-facts.md` — what compiles in the cloud container, measured.

The authoritative specification derived from all of this is `../DESIGN.md` and `../BUILD-PLAN.md`.
